🛡️ Local Legal Contract Delta & Redline AuditorStandard Retrieval-Augmented Generation (RAG) isolates document sections, failing to recognize when vital contract terms are subtly edited, shifted down a page, or completely stripped out by an opposing party.The Local Legal Contract Delta & Redline Auditor solves this challenge by implementing a Parallel Coordinate Chunking framework. Using layout-aware structural chunking, a structural alignment similarity matrix, and local LLMs via Ollama, it identifies and flags hidden liability shifts, omitted clauses, or changed payment terms without sending sensitive legal data to the cloud.🏗️ Core Architecture & SkillsHierarchical Layout Chunking: Rather than splitting text blindly by character counts, the auditor utilizes layout boundaries to isolate true legal clauses and paragraphs.Sequence Alignment Vector Matrix: Generates contextual embeddings for every paragraph and computes an $M \times N$ cross-document similarity matrix using NumPy. This tracks paragraphs even if the client inserts text that pushes clauses down the document.Contextual Asymmetric Delta Evaluation: Isolates and extracts only the modified, omitted, or freshly inserted clauses, passing them dynamically into a targeted local LLM context window for risk mitigation analysis.🛠️ Ecosystem StackOllama (llama3.1 & nomic-embed-text): Fully local inference engine handling semantic text embedding generation and advanced legal reasoning.Streamlit: Wide-layout operational user interface providing an elegant side-by-side comparative ledger.pdfplumber: Layout-preserving PDF extraction engine capable of maintaining precise paragraph blocks.NumPy: Fast vector similarity calculations for structural alignment mapping.🚀 Quick Start & Installation1. Upload: Drop your original master agreement (MSA/NDA) and the client's returned counter-offer into the sidebar interface.Matrix Generation: The application vectorizes every block of text, calculating exact coordinate cross-matches.Delta Logic:Wording Shifts: If a paragraph matches semantically but text has changed, llama3.1 audits the changes for liability shifts.Deletions: If an original clause finds no strong match anywhere in the counter-offer, it is automatically flagged as a complete deletion.Insertions: If the client introduced completely new legal language, it is separated and analyzed as a fresh risk factor.⚙️ Configuration TuningAlignment Sensitivity (Threshold): Accessible via the sidebar slider. Higher thresholds (e.g., 0.85) create a strict match framework, flagging even minor syntax modifications for deep LLM evaluation. Lower thresholds (e.g., 0.70) allow for heavy stylistic paraphrasing before flagging text as structurally altered.
